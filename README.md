# Cloud & Capital contributor context

Shared reference material for contributors and AI coding assistants working on Cloud & Capital projects.

Start with [CLAUDE.md](CLAUDE.md) for contribution and review guidance. This repository contains context, not a runnable application or a package installer. Apply the guidance alongside the instructions in the project being edited.

## Keep context current

Each project's current README, source, tests and applicable contributor instructions define its supported behavior. Check those sources for commands, data contracts, release versions, coverage and limitations. Update this reference when that behavior changes instead of copying old capability claims into new work.

[Cloud & Capital](https://cloudandcapital.com) brings the tools, services and writing together.
